# Research digest: 2026-11-23
> **TL;DR:** "Rewrite *anything*" tools are the breakout theme (craft-anything, rust-anything, fast-anything). Agent skills are shifting from big collections to single-purpose visual skills (diagrams, animation, sprites). Beware a star-farmed ring of ~10 "Blender AI MCP" repos.

_First digest. Stars are a snapshot at ~23:20 KST. Age = days since repo creation._

## Top picks
1. **[storytold/craft-anything](https://github.com/storytold/craft-anything)**: 41.8k★ in 23 days. Explains how any software works and helps you build your own version. The biggest new repo of the month.
2. **[erkamyaman/rust-anything](https://github.com/erkamyaman/rust-anything)**: 8.5k★ in 7 days. Migrates an app to Rust piece by piece, checked against the original's recorded behavior. Its counterpoint, **[EL4CTEO/fast-anything](https://github.com/EL4CTEO/fast-anything)** (2.8k★ in 2 days), only ports the hot 5% found by profiling.
3. **[vercel-labs/ui](https://github.com/vercel-labs/ui)**: 6.7k★. Vercel's library of UI behaviors meant for agents to build interfaces with. Worth watching as an official pattern.
4. **[sybil-solutions/skill-distill](https://github.com/sybil-solutions/skill-distill)**: 485★ in 2 days. Turns a good Claude Code / Codex session into a skill an open-weight model can follow. A fresh idea in the skills space.
5. **[KKKKhazix/agent-autoloop](https://github.com/KKKKhazix/agent-autoloop)**: 6.4k★. Lets a CLI agent pick up and follow through work in the background, pinging you with a card only when it needs a decision.

## Watch out
- **Star-farmed "Blender AI MCP" ring**: ~10 near-identical repos (e.g. `blender-ai-copilot-studio/-flow/-assets/-desk/-lab/-hub`) from throwaway accounts, all created 2026-11-12 with ~500★ each and no detected code. Treat as likely malware lures; do not install.
- **MSNightmare/FastUnlock** claims a Windows lock-screen "0day" bypass. Skipped.
- Several high-star repos this week are recompilations of commercial games (GTA 6, Zelda, Xbox titles). Skipped per criteria.
